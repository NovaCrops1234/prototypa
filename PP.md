# Privacy Policy — Nisama

Last updated: August 2026

---

## Overview

Nisama is a Discord AI bot. This policy explains what data is collected, how it is used, and how you can request its removal.

---

## What Data is Collected

When you interact with Nisama, the following data is stored:

| Data | Purpose |
|---|---|
| Discord User ID | Identifies your account across sessions |
| Discord Display Name | Stored internally for developer reference only |
| Name you introduce yourself as | Used by Nisama to address you correctly |
| Conversation history | Provides Nisama with context for replies |
| Notable facts extracted from conversations | Shared memory system so Nisama can reference things across users |
| Slash command usage | Anonymous usage statistics for the developer |
| Messages sent via `/send` | Logged for moderation purposes |
| Proactive messaging settings | Stores whether you have enabled or disabled Nisama's proactive messages |

---

## What Data is NOT Collected

- Passwords or credentials of any kind
- Payment information
- Any data outside of your Discord interactions with Nisama

---

## How Data is Used

All collected data is used solely to power Nisama's AI chat functionality and improve the experience. Specifically **Conversation history**, **Your introduced name**, **Extracted facts**, and **Slash command usage**.

---

## Data Storage

All data is stored in a PostgreSQL database. Data is retained indefinitely unless you request deletion.

---

## Your Rights

For privacy concerns or data deletion requests, contact the developer directly through Discord.

This permanently removes your conversation history, extracted facts, user profile, and known name from the database.

---

## Changes

This policy may be updated at any time. Continued use of Nisama after changes constitutes acceptance of the updated policy.

---

## Contact

For questions or concerns, contact the developer directly through Discord.
